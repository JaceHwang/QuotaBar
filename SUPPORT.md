The transaction installer uses the user Applications folder: `~/Applications/QuotaBar.app`. Finder's sidebar commonly points to `/Applications`; use Command + Shift + G to find the user folder.

Reports should include the exact app version, macOS version/architecture, menu bar quota/icon choice, floating visibility if relevant, reproduction and expected behavior. Remove credentials, account details and unrelated screenshots. Windows standalone and Developer ID notarization are not currently supported deliveries.
