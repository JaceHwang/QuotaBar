# Validation archive

This directory stores version-scoped evidence, schemas, and documentation snapshots retained for
audit or automated tests. These files describe the version and source state named in each file;
they are not current installation instructions.

- `windows-v0.3.3.json` and `windows-v0.3.3.schema.json` are the canonical sanitized Windows v0.3.3
  real-device evidence and schema used by the release-chain tests.
- `windows-v0.3.3-real-device-template.md` and the Task 5/Task 6 reports explain that historical
  validation process and remain linked to automated tests.
- The dated documentation and macOS release reports record checks performed on those dates.

For current releases, use the [documentation index](../README.md), the
[macOS v0.4.0 release notes](../releases/macos-v0.4.0.md), and the
[Windows v0.4.1 release notes](../releases/windows-v0.4.1.md).
