# Privacy

Official account services and the bundled Codex app-server provide quota and identity data. Credentials are managed by the official runtime in the isolated local account directory. The app does not copy desktop credentials, publish account data or add analytics.

AppKit UI displays account details locally. Diagnostics contain process/phase flags, not credentials or email. No host-window scanning or Accessibility permission is required. Mouse monitoring is used to dismiss the detail card; no global keyboard monitor is installed.

Release source snapshots and provenance include public source hashes and commit identifiers, not account data. Remove private details from issue logs and screenshots. Uninstall preserves account credentials; sign out first to clear authentication through the supported runtime flow.
