## 目标与当前边界

独立应用通过内嵌官方运行时查询额度，使用隔离账户和官方登录，不依赖 Codex 桌面 UI、插件 hook、宿主窗口扫描或辅助功能定位。

当前 macOS：Swift 6、AppKit、NSStatusItem、官方 Codex 0.144.1 app-server、Service Management 登录启动。声明 macOS 14+ Apple Silicon，实测 macOS 27.0。公开包为本地签名，未完成 Developer ID 公证。

Windows 独立版：当前采用.NET 10 LTS、WPF与WinForms NotifyIcon，官方codex.exe 0.144.1和独立账号目录。原生CI通过，用户报告Windows 11验收通过；具体设备版本、DPI和逐项日志未提供，不推断覆盖全部边缘场景。仅复用历史插件视觉实现，不恢复UIA、宿主绑定或插件采集。契约样例位于 `contracts/`。

## 当前代码与交互契约

- `native/Sources/CodexQuota`：菜单栏、详情卡、设置与应用生命周期。
- `native/Sources/QuotaCore`：账户/额度/Token 数据、官方 app-server、刷新状态与格式化。
- `native/Tests`：保留独立版仍使用的协议、账户、状态、格式、布局和详情卡测试。
- `scripts/`：构建、事务安装、打包、来源验证和仓库校验。
- `contracts/`：脱敏协议样例；无旧插件源代码或旧安装器。
- 额度是账户周期额度，不是 API 现金余额。字段缺失不能转成零；Bank 只读。
- 后台约 60 秒刷新，失败退避最长 300 秒；打开详情、唤醒、网络恢复可触发查询。
- 菜单栏保留双周期剩余额度与重置日期，两行完整且垂直居中已由用户实机确认。
- 原详情卡视觉沿用用户批准的设计，跳过效果图；清理不改变其外观与交互。
- 凭据继续保存在既有隔离 `CodexHome`。兼容目录名沿用，不复制普通 Codex 账户。
- 默认跟随系统语言/主题，支持简中、繁中和英文；关闭设置继续常驻。
- 安装器保留停用旧入口及失败恢复的迁移保护；不再提供恢复旧插件的动作。
- 不提供多账号并行、历史趋势、自动安装更新或自动兑换 Bank。

### 必须一致的详情状态机

以 `QuotaDetailInteractionState.swift` 为纯逻辑基准，Windows建议移植为无UI依赖的状态类型并测试：

1. 是否显示 = 锁定，或固定，或（鼠标在浮窗/其详情内且未禁止悬停）。
2. 初次悬停预览；指针从按钮进入其详情仍算在同一交互区域，不因穿过边界立即闪退。
3. 点击切换固定。再次点击取消固定时，若鼠标仍在区域内，暂时禁止悬停重新打开，直到真正移出。
4. 锁定与固定分开：上锁清除固定；解锁清除悬停禁止并恢复指针追踪。锁定本身不阻止应用退出或浮窗关闭。
5. 外部交互清除固定/悬停，但保留锁定。入口切换时协调器清理另一入口状态，避免一个详情卡被两套状态争抢。
6. 关闭/禁用浮窗重置其全部交互状态和计时器；浮窗来源详情即使锁定也收起。菜单栏来源详情不应被无关的浮窗禁用动作误关。

Windows若用MouseLeave替代指针追踪，需要将按钮和详情视为联合区域；不能只依赖按钮MouseLeave。先测试纯状态再测试窗口事件、重叠窗口和真实鼠标。

### 数据、刷新和恢复契约

- 状态枚举：loading、ready、offline、needsLogin、signingIn、unsupported。登录失效、网络失败和不支持协议要分开显示，不能统统变成0额度。
- 收到额度后约60秒安排下一次查询；协调器5秒tick检查调度。请求20秒超时、单次额度请求并发保护；失败退避15/30/60/120/240/300秒封顶，成功重置。
- 休眠停止主动刷新，唤醒、网络恢复和主动刷新可触发查询；needsLogin/signingIn/unsupported不持续自动请求。保留上次成功时间与旧数据的新鲜度提示。
- 接收账号清空/退出事件立即清空展示；身份、Token、额度分别解码，局部缺失不能让整个UI崩溃。支持请求响应和额度更新通知，对照 `contracts/rate-limits/`。
- 会话由应用负责启动、退出和有界恢复；Windows建议用专属进程树管理（例如Job Object）确保退出不残留，不扫描/杀死其他Codex进程。实现选择需在Windows验证。
- 日志只记录阶段、错误类别、请求时间与非敏感诊断；不输出OAuth凭据、原始账号响应或完整认证文件。

### Windows平台差异与实施前决策

标准 `NotifyIcon.Icon` 是通知区域图标，`NotifyIcon.Text` 是悬停提示，不是任意宽度双行任务栏标签。来源：[Microsoft NotifyIcon概览](https://learn.microsoft.com/en-us/dotnet/desktop/winforms/controls/notifyicon-component-overview-windows-forms)、[Text属性](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.notifyicon.text)。因此直接设置Text不能完成macOS“图标/具体额度信息”视觉对齐。

W0须做原型并记录结果：标准托盘图标+额度tooltip作为基础能力；若要求常驻宽文本，可研究单独的任务栏邻近信息窗，但它是替代显示方式，涉及自动隐藏、全屏、多屏与系统版本适配，不能默认为已满足用户原需求，也不应重新绑定Explorer内部UI结构。完成原型后明确设置项语义及用户认可的等价方案，再继续该项实现。浮窗开关与托盘可用性不依赖这个决策。

Windows路径计划使用每用户应用数据目录下独立的QuotaBar/CodexHome；格式与路径将在实施时确定。优先原子写入带schema版本的偏好文件，迁移失败保留旧文件。macOS现有键可作为语义映射：`standalone.floating.enabled`默认true、`standalone.floating.origin`有限坐标、`standalone.status.showsQuota`默认true、`standalone.theme`与`standalone.language`默认system。不要求Windows读取macOS UserDefaults或复制其绝对路径。详情固定/锁定属于当前会话状态，不能误加为永久启动选项。
