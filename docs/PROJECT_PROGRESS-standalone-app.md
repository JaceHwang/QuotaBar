## 目标与完成标准

将 Codex Usage Sidebar 改为 macOS 菜单栏和 Windows 系统托盘应用，避免 Codex UI 更新引起标题栏定位、窗口结构和显示条件适配。保留官方 app-server 数据链路与现有原生实现。

目标独立程度：不需要打开 Codex 桌面版、不需要安装 Codex 插件、正式安装包携带已验证运行时而不要求用户手动安装 CLI。仍依赖官方账户服务与 app-server 协议，不能承诺无需协议维护。

最终验收必须同时满足：

- Codex 桌面版未运行时，应用可登录、查询和展示额度。
- 纯独立模式不调用 Accessibility/UI Automation 扫描，不依赖 Codex 前台状态、标题栏、主题或语言。
- 菜单栏/托盘常驻，详情关闭后继续运行，明确退出后没有残留采集子进程。
- 网络、认证、休眠、运行时退出及可选字段缺失都有可解释的状态和恢复行为。
- 两平台分别完成安装、升级、卸载与实机验收，发布资产可追溯且版本遵守 Release Please。

## 每次开发的读写规则

1. 开始前读取本文件、根目录 `AGENTS.md`，恢复 `.project-board/`；检查当前分支、工作区差异与最近证据。不得覆盖用户已有修改。
2. 确认当前授权和阶段依赖，只选择可执行的任务；进入产品开发前重新核对技术方案与具体实施范围。
3. 将当前任务改为进行中，记录负责人/执行平台、开始日期和当前具体目标。看板最多一项 `doing`。
4. 每完成一个有意义的里程碑，更新任务状态、改动文件、验证命令及结果、设计决策和下一步。失败、部分完成和未执行必须如实记录。
5. 中断、交接或结束本次开发前，更新“当前阶段/最近更新/下一步”和工作记录，同步看板并执行其 `validate`。本文件可手动维护；看板生成文件只能通过工具更新。
6. 文档与实际代码或测试冲突时，以现场证据为准并修正文档。旧项目历史、源码实现和 CI 通过不能充当新独立应用的实机或发布证据。

状态：待开始 → 进行中 → 已实现待验证 → 已验证 → 已发布。另可标记阻塞或取消。阶段完成以验收条件为准，不能仅按代码量或时间判断。

## 技术方案与复用范围

| 层次 | macOS | Windows | 约束 |
| --- | --- | --- | --- |
| 原生界面 | Swift 6、AppKit、NSStatusItem | C#、WPF、WinForms NotifyIcon | 首轮不同时重写技术栈 |
| 数据核心 | SidebarCore、AppServerClient、JSONRPC | Core、AppServerSession、AppServerProtocol | 保留解码/格式化，隔离宿主依赖 |
| 运行时 | 管理的官方 Codex 子进程 | 管理的官方 codex.exe 子进程 | 固定已验证版本、stdio、受控退出 |
| 登录 | 官方浏览器流程/设备码流程，按版本验证 | 同左 | 隔离 CODEX_HOME，不复制桌面版凭据 |
| 系统集成 | 菜单栏、设置窗口、可选登录启动 | 托盘、详情/设置窗口、可选登录启动 | 单实例，关闭窗口不等于退出 |
| 共用资产 | contracts 脱敏样例、状态契约、文案与验收规则 | 同左 | 两套实现以同一契约验证 |

首版支持范围保持 macOS 14+ Apple Silicon、Windows 11 x64。Intel Mac、Windows ARM64 和 Linux 不纳入首版验收；扩大范围需单独确定成本及证据。Windows 开发启动时核对 .NET 支持周期，选择受支持的 LTS，不能因当前源码使用 .NET 8 就永久锁定它。

备选 Tauri 2/Rust/Web UI 可在长期需要统一界面或支持 Linux 时重新评估；Electron 可用于偏重 Web 的产品，但本次没有足够收益抵消重写与运行时维护成本。

保留：周期额度、多额度桶、账号、套餐、Credits、Bank、Token、解析契约、刷新/恢复经验及可复用详情控件。

移除独立模式的依赖：AX/UIA、宿主窗口匹配、标题栏防碰撞、前台/页面显示门禁、跟随 Codex 主题和渲染进程语言、SessionStart 才能启动的路径。旧模式是否保留仅在迁移设计时决定，不能让它成为独立运行的必需条件。

## 数据与交互契约

- 账户周期额度不是 API 现金余额，不用 Token 数推算剩余百分比，不把百分比换算为金额。
- 周期长度使用服务端字段，不永久硬编码五小时/七天。多额度桶有明确选择/展示规则，可选字段缺失显示未提供，不能转成零。
- 独立应用登录账号可以不同于 Codex 桌面版；详情明确显示当前查询账号。官方运行时负责凭据，应用不记录令牌或复制普通 CodexHome。
- 本地通知与主动查询结合。不能假定自有 app-server 会即时收到其他客户端的全部消耗事件，P1 必须测量跨客户端更新延迟。
- 刷新候选值为后台约 60 秒、打开详情时刷新、请求合并、失败指数退避、休眠暂停、唤醒/网络恢复刷新；最终参数由 P1/P2 证据确定。
- 重置时刻到达后查询服务端，不自行补满。过期快照保留但明确标记更新时间和过期；首次无数据、认证失效、离线、协议不支持分别呈现。
- Token/Credits/Bank 区域失败局部降级，不阻断主额度。Bank 首版只读，不自动兑换。
- macOS 菜单栏可显示简短比例；Windows 托盘采用图标、悬停提示及点击详情，不承诺任务栏长文本或强制让图标显示在溢出区外。
- 默认跟随系统主题和语言，设置可覆盖；保留简中、繁中、英文支持。
- 首版不加入多账号同时监控、同步服务、历史趋势、自动 Bank 消耗或自动下载安装更新。检查更新入口与后续自动更新区分。
