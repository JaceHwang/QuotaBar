# QuotaBar v1.6.0

## 发布范围

用户已授权合并 PR64、更新文档和README截图并公开双端1.6.0。版本由 Release Please 生成，使用 Release-As 指定1.6.0，不覆盖旧资产。

- macOS：下载字节进度、退出清理交接、安全失败阶段/系统错误码；启动后10秒首次检查。
- Windows：助手就绪等待从10秒扩为120秒，保留取消、提前退出、来源校验与回退；偏好和消息历史在无效句柄错误时启用有备份的兼容写入。
