# 消息中心统一列表设计

用户要求将未读提醒和历史消息合并到一个列表，未读字体加粗并带背景阴影，点击后标为已读并恢复默认样式。用户查看三种效果图后选择 C：未读为柔和阴影的圆角卡片，已读为平面默认背景；选中和键盘焦点须与未读状态可区分。视觉参照 [C 概念图](assets/unified-message-list-c.png)，图中文字仅是示例，真实详情取消息记录。

延续消息产生时间倒序、左右列表详情、窄屏返回列表、全部已读、消息保存和失败提示；未读计数可见，不自动选中或读取下一条。点击当前消息仅在已读持久化成功后移除该条未读视觉状态；失败时仍保留未读样式。支持 macOS 和 Windows、浅色和深色、三种语言、键盘操作和系统缩放。预览/测试消息不入历史，消息不删除；无公开发布授权。

比较过 A（灰色整行）和 B（浅蓝整行），用户明确选择 C，以圆角与轻阴影强调未读状态，不将概念图中的模拟文案当作产品数据。
