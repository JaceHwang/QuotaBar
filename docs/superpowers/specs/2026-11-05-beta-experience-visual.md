# 内测体验视觉决策简报

- 目标：在 QuotaBar「关于应用」中增加可辨识、默认关闭的内测入口，让用户清楚理解内测版本可能不稳定，并通过多次手动确认才开启。
- 用户选择：2026-11-05 选择 **B：独立内测卡片**；[B 概念图](assets/beta-experience-b.png)是视觉参考，不是实际应用截图，其中版本号和链接为示例。
- 视觉特征：沿用现有设置侧栏、原生控件与克制的蓝色操作；版本与更新区域下方增加独立卡片，卡片包含「内测体验」、清晰的关闭/开启状态、简短说明和开关。默认关闭使用灰色开关；卡片的浅蓝强调不应被误解为功能已开启。
- 确认体验：请求开启后提供两个彼此独立、可取消的确认步骤；说明内测版可能不稳定，以及开启仅允许接收更新，安装仍需用户操作。最终确认成功之前，开关一直保持关闭。图中 2/2 为第二步示意，不代表第一步可省略。
- 跨平台约束：保留 macOS AppKit 与 Windows WPF 原生交互；兼顾亮色、深色、系统高对比、键盘与读屏，窄窗口不裁切说明或按钮。图像生成文字与图中附带的示例控件不构成最终文案或功能协议。
- 用户同时确认：GitHub 预发布包允许公开下载；客户端内测开关只控制是否向该用户提供内测更新，并非访问权限控制。
