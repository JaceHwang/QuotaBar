# QuotaBar Windows 独立版设计

用户目标：实现与当前 macOS 独立版一致的额度采集、浮窗、详情、设置和安装能力，包括尚未发布的悬停关闭按钮。完整需求以 [开发进度](../../PROJECT_PROGRESS-standalone-app.md) 的功能矩阵和 W0–W6 为准。

## 已确定的平台方案

用户明确选择 Windows 托盘只显示图标，额度放在提示与浮窗。NotifyIcon 不承载宽文本，且不新增任务栏邻近信息窗。“任务栏显示额度信息”控制提示中的额度；浮窗独立保存开关，由右键菜单和悬停关闭按钮控制。

采用 .NET 10 LTS、WPF 与 WinForms NotifyIcon。先支持 Windows 11 x64，自包含发布，不要求预装 .NET 或 Codex。官方 Codex runtime 固定 0.144.1，通过 stdio app-server 和独立 CODEX_HOME 登录。Core 为 net10.0 无UI库，在 macOS 也能执行行为与协议测试；Windows UI 为 net10.0-windows，可交叉编译，真实UI验收需Windows设备。

## 模块边界

- QuotaBar.Core：解析、模型、刷新/详情状态、偏好存储、JSON-RPC会话、子进程运输。
- QuotaBar.Windows：应用协调器、原生托盘、浮窗、详情、设置、屏幕与DPI转换、系统通知、启动项。
- QuotaBar.Core.Tests：不依赖UI的契约、状态、失败恢复和事件序列测试。
- scripts：Windows runtime下载核验、自包含包与来源摘要、每用户事务安装/升级/回退/卸载。

## 视觉与交互约束

沿用用户批准的现有 QuotaBar 设计，跳过效果图；参考当前AppKit实现与仓库品牌资源。保留两行额度/日期、百分比色彩、账号页脚、Token柱状展示、Bank只读明细、锁定和可调高度。WPF使用DIP和系统字体；深浅色/高对比、键盘焦点和可访问名称必须可用。浮窗非激活且可拖动，关闭区域独立命中，鼠标移入才显示且尺寸不变。

详情显示由纯状态机驱动。浮窗关闭保存false、清理其详情状态，但托盘与后台继续。关闭设置不退出，退出清理所有自有子进程。屏幕恢复处理负坐标和DPI变化，不扫描Codex或Explorer内部窗口树。

## 数据与安全

字段缺失保持不可用，不能变0；额度与Token分别处理。刷新60秒、请求20秒超时、失败退避至300秒、单请求保护；登录失效停止轮询。退出账号清理缓存且禁止晚到响应恢复旧账号。会话失效有界重启。凭据保留在每用户隔离目录，不读取桌面凭据，日志不输出响应/令牌。

## 验证与交付

Core测试覆盖共享fixtures和故障序列；Windows构建覆盖WPF和自包含包；设备验收另记录真实账户、Hover/Close/Drag、锁定、DPI/多屏、Explorer重启、休眠与退出清理。没有设备证据不能宣称完成。安装必须可恢复，保留账号及偏好。当前授权为开发和候选打包，不公开发布，不改产品版本。
